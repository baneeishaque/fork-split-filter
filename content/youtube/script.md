## 10. The trade-offs, honestly

On-screen code: `standalone · subprocess git · snapshot polling · substring filter`

**en** — Every choice costs something. A standalone app ships today but lives beside Fork. Shelling out to git keeps
  git authoritative but spawns a process. Polling is simple but two seconds stale. And a substring filter is
  predictable but not fuzzy. The docs record each decision and its alternative.
